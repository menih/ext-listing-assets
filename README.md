# ext-listing-assets

Screenshots for the Bullseye VS Code Marketplace listings, referenced from each extension's README.

Each image is rendered in a headless browser from the extension's **real** shipped panel over an
**invented** fixture — no real account, key, balance, session, agent, folder, hostname or person
appears in any of them.

| Folder | Extension |
|---|---|
| `bullseye-backlog/` | BullseyeBacklog |
| `fleetview/` | FleetView |
| `deepagent/` | DeepAgent |
